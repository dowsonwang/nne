# TikTok Shop 选品调研：工具、数据、数据从哪来

> 调研日期：2026-11-04。来源以英文资料为主，很多是工具厂商自己的博客，工具之间互相"拉踩"的结论要打折扣。价格、覆盖国家、功能每月都在变，下单前以官网为准。

---

## 一、先搞清楚整体：TikTok 选品在选什么

TikTok Shop 是**内容电商**（兴趣电商）：用户在刷视频、看直播时被"种草"，冲动下单。跟亚马逊（用户主动搜索）的逻辑不一样：

| | 亚马逊 / 传统货架电商 | TikTok Shop |
|---|---|---|
| 流量来源 | 用户主动搜索关键词 | 算法推荐视频、直播 |
| 选品核心问题 | 搜索量大、竞争小吗？ | **这个东西能不能拍出让人停下来的视频？** |
| 出单主力 | 店铺自己 | **达人（带货博主）** + 自己的账号 + 广告 |
| 典型爆品 | 刚需、复购 | 视觉冲击强、15 秒能讲清楚、价格低、可冲动消费 |

所以 TikTok 选品看的不只是"卖了多少"，还要看**是谁在卖、用什么视频卖、有多少达人在卖、是不是还在涨**。

## 二、工具分两大类

### A. 官方工具（免费，但只能看自己 / 或只能看趋势）

| 工具 | 在哪 | 作用 | 局限 |
|---|---|---|---|
| **TikTok Creative Center（创意中心）→ Top Products** | ads.tiktok.com/business/creativecenter，Inspiration 菜单下（仅网页端） | 看**广告里**正在热推的商品，按国家、类目筛选；排序参考广告花费、点击率、转化等 | 只反映投广告的商品，不是全站销量；部分功能需登录商务账号 |
| **Creative Center → Trend Discovery / Keyword Insights** | 同上 | 热门话题标签、热门音乐、热门视频（近 30 天）、广告关键词 | 只看内容热度，没有销量 |
| **Seller Center → 商品机会（Product Opportunities）** | 卖家后台 → 商品 → 商品机会 | 平台推荐的"有需求、供给不足"的商品，附带预估销量 | 需要有店铺；是平台想让你卖的，不一定适合你 |
| **Seller Center → 数据罗盘（Data Compass）/ 店铺分析** | 卖家后台 | 自己店铺的流量、GMV、转化率、视频/直播/达人带来的订单 | **只能看自己的店**，看不到竞品 |
| **联盟中心 / 达人市场（Affiliate Center / Creator Marketplace）** | 卖家后台 | 找达人、看达人带货数据、发样品、设佣金 | 主要用于找人，不是选品 |

**结论：官方工具看不到别人卖了多少。要看竞品和全市场，必须用第三方工具。**

### B. 第三方数据工具（付费，行业主流）

| 工具 | 背景/定位 | 强项 | 弱项 | 价格（大致，以官网为准） |
|---|---|---|---|---|
| **FastMoss** | 国内团队做的，中文友好，国内卖家用得最多之一 | 功能最全：商品、店铺、达人、视频、直播、榜单、类目大盘、竞品监控；覆盖国家多（宣称 19~30+ 个市场）；有 API / MCP | 功能多上手门槛高；有评测说其**视频数、达人数不太可靠**，GMV 大盘可用 | 有免费版，付费分多档，见 fastmoss.com/pricing |
| **Kalodata** | 美区卖家用得很多 | 类目一路下钻到 SKU；按"卖过多少货"而不是粉丝数找达人；历史数据较深、直播分析较细；有 API | 小店铺、小达人的销量估算偏软 | 有报道起步约 $45/月，见 kalodata.com/pricing |
| **EchoTik** | 低价入门型 | 便宜、有免费版；商品/店铺/达人/视频/直播都有 | 筛选条件少、历史浅、长尾小店覆盖差 | 有报道 Basic 约 $10/月起（厂商自述） |
| **Tabcut（特看）** | 偏数据团队 | 提供 API、自定义报表 | 需要技术能力 | 见官网 |
| **PiPiADS 等广告情报工具** | 看广告素材 | 看竞品投了哪些广告、素材怎么拍 | 不是完整选品工具 | 见官网 |

> 国内同类型的抖音工具（蝉妈妈、飞瓜、灰豚等）逻辑完全一样，只是数据源换成抖音。做过抖音的人上手 FastMoss 会很快。

**怎么选（多数评测的共识）：**
- 刚起步 / 预算紧：EchoTik 免费版 或 FastMoss 免费版先摸一摸
- 主做美区、重点找品+找达人：Kalodata
- 做多国、需要看大盘和直播：FastMoss
- 规模大了：**买两个互相校验**，或者接 API 自己做报表

## 三、选品要看哪些数据

按"一个商品值不值得做"的判断顺序：

### 1. 销售数据 —— 有没有需求
| 指标 | 含义 | 怎么看 |
|---|---|---|
| **销量 / GMV（成交额）** | 近 7 天 / 30 天卖了多少件、多少钱 | 看绝对值，更要看**趋势**：是在涨、平稳还是已经掉头 |
| **销量增长率** | 环比增速 | 正在起量的品机会最大；已经爆过一轮的品可能晚了 |
| **客单价（价格带）** | 售价 | TikTok 爆品集中在约 **$10–$30**（有的说 $15–$50）；太便宜佣金和利润太薄，太贵很难冲动下单 |
| **持续性** | 是一次性爆还是持续出单 | 只爆一个视频的品风险大；连续几周稳定出单更可靠 |

### 2. 达人 / 内容数据 —— 能不能复制
| 指标 | 含义 | 怎么看 |
|---|---|---|
| **带货达人数** | 有多少达人在推这个品 | 多个达人都能卖动 = 是**品**在驱动，不是某个大网红的个人效应 |
| **带货视频数 & 新增视频数** | 有多少视频挂了这个商品 | 视频数增长快说明达人愿意推；但视频太多也可能已经饱和 |
| **小达人爆款** | 粉丝少（如 <5 万）的账号拍出高播放（如 50 万+） | 很强的信号：说明内容本身好卖、可复制 |
| **视频播放 / 点赞 / 评论** | 内容热度 | 结合"播放→销量"看转化效率 |
| **出单来源占比** | 视频 / 直播 / 商品卡（搜索）各占多少 | 判断这个品主要靠什么渠道卖，决定你怎么打 |

### 3. 竞争数据 —— 你还能不能进
| 指标 | 怎么看 |
|---|---|
| **在售店铺数 / 头部集中度** | 一家独大还是分散？分散更容易进 |
| **同款数量和价格战** | 同款太多、价格被打穿，就别进了 |
| **广告投放情况** | 竞品是否大量投广告（PiPiADS / Creative Center 看） |

### 4. 利润 —— 算账
```
单件利润 = 售价 − 采购成本 − 头程/尾程物流 − 平台佣金(类目费率)
          − 达人佣金(常见 10%~30%) − 样品成本 − 广告费 − 退货损耗
```
有卖家的经验线是：**保守情况下利润率低于 20% 就不做**（单一来源经验值，参考用）。
佣金不能只看比例：20% 佣金但 50 个人买 1 个，不如 10% 佣金 10 个人买 1 个——达人更愿意推转化高的品。

### 5. 供应链 —— 能不能拿到货
- 在 1688 / 工厂找到同款或更优款，看成本、起订量、发货速度
- 是否有侵权风险（品牌、专利、外观）、是否属于平台限售类目
- 物流：体积重量、是否易碎、是否带电

## 四、数据是怎么来的（重要：都是估算）

**第三方工具没有接入 TikTok 后台，所有"别人卖了多少"的数字都是估算出来的模型结果，不是真实账本。**

原理大致是：
1. **采集公开可见的数据**：商品页上显示的"已售 xx 件"、价格、评论数；达人主页；视频的播放/点赞/评论；直播间在线人数、商品弹出；店铺页面等。（FastMoss 自称"合规采集公开信号"，第三方文章普遍说就是爬取。）
2. **定时反复抓取，算差值**：比如商品页显示的累计销量今天比昨天多了多少，推出日销量。
3. **用算法模型补全和校准**：把销量分摊到具体视频、达人、直播，估出 GMV。FastMoss 称用 1500+ 天历史数据训练、持续校准。

**准确性：**
- 没有独立权威的准确率测试。各种评测说法：误差 ±15%~25%、快速起量的品偏差 25%~40%、整体偏乐观 15%~20%……方法都不透明。
- 共识：**大盘 / 类目汇总数据比较靠谱；单个小店、小达人的数据很软；"昨天"的数据最不准**（还没校准完）。
- Kalodata、EchoTik 自己也声明数据不适合用于结算等需要精确的场景。

**所以正确用法：**
- 第三方数据用来看**方向和相对大小**（哪个品在涨、A 比 B 卖得好），不要当绝对值。
- 同一个品在两个工具里交叉看，差太多就存疑。
- 自己开店后，用 Seller Center 的真实数据去校验工具数据，心里就有数了。

**官方数据怎么拿：** Seller Center 后台直接看（仅自己店）；TikTok Shop 开放平台 API（partner.tiktokshop.com）可以拉自己店的订单、商品等数据，用于做 ERP / 报表。

## 五、一套实际可用的选品流程

1. **找方向**：Creative Center Top Products + Trend Discovery 看什么在火；Seller Center 商品机会看平台推荐。
2. **用第三方工具筛**（如 FastMoss / Kalodata 的商品榜单）：
   - 目标国家、类目
   - 价格 $10–$50
   - 近 7/30 天销量在**增长**
   - 带货达人数 ≥ 若干（多人能卖）
   - 有小达人爆款视频
3. **看内容**：把卖得好的那几个视频全部看一遍——卖点是什么、怎么拍的、你能不能拍出来/找人拍出来。
4. **看竞争**：在售店铺数、同款价格、是否已有价格战。
5. **算利润 + 找货源**：1688 比价、算全链路成本，利润率太薄的直接砍。
6. **小规模测试**：上架后寄样给 10–20 个小达人（或自己拍视频），跑 1–2 周看真实数据（Seller Center），再决定是否加大投入。
7. **持续监控**：工具里收藏竞品店铺 / 商品，看它们新上了什么、哪条视频起量了。

## 六、待你决定 / 需要进一步确认的

- 你做哪个国家站点（美区、东南亚、英国……）？不同工具覆盖差异大。
- 你的角色：自己开店卖货，还是做达人带货（联盟）？后者更看佣金和样品。
- 建议先注册 FastMoss 和 Kalodata 的免费/试用账号，用**同一批商品**对比数据，再决定付费。
